#Ejercicio 4

 ##¿String es un tipo por valor o por referencia?

String es un tipo por referencia en C#.

---

## ¿Qué secuencias de escape tiene el tipo string?

Algunas secuencias de escape son:

- \n → salto de línea
- \t → tabulación
- \\ → barra invertida
- \" → comillas dobles
- \' → comilla simple

---

## ¿Qué sucede cuando se utiliza el carácter @ y $ antes de una cadena?

### @
Permite escribir cadenas literalmente sin usar secuencias de escape.

Ejemplo:

@"C:\Usuarios\Documentos"

### $
Permite interpolar variables dentro de una cadena.

Ejemplo:

$"Hola {nombre}"
